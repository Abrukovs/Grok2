# Grok2 — Система ежедневного анализа ставок (Лайнер)

Репозиторий содержит методологию и принципы работы системы ежедневных беттинг-рекомендаций, разработанной совместно с Grok (xAI).

Цель: сохранение логики на случай сброса контекста, переноса на другой сервер или работы с другим ИИ.

## Основные файлы

- `METHODOLOGY.md` — подробное описание логики выбора матчей и общих принципов.
- `STYLE.md` — стиль рекомендаций и формат выдачи.

## Кратко о системе

Консервативный подход к выбору 1–2 событий в день:
- Коэффициенты **1.50–2.80** (decimal)
- Высокая вероятность прохода
- Приоритет нижним лигам / кубкам / менее хайповым событиям, когда топ-лиги пустые
- Подробный анализ формы, травм, odds, home/away, специальных факторов (высота, back-to-back и т.д.)

Система используется для ежедневного брифа (проект **Лайнер**).
