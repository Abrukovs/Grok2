# Стиль рекомендаций и формат выдачи

## Язык
Русский (основной). Можно давать ключевые термины на английском (ML, spread, odds и т.д.).

## Структура ответа (рекомендуемая)

1. **Краткий итог / топ-пик**  
   Один самый сильный исход дня + коэффициент.

2. **Почему именно этот**  
   3–5 ключевых аргументов (статистика + контекст + рынок).

3. **Подробный разбор**  
   - Актуальные коэффициенты  
   - Форма  
   - Травмы  
   - Оценка вероятности vs implied  
   - Риски

4. **Альтернативы** (если есть)  
   Кратко, почему не выбраны.

5. **Дисклеймер**  
   Ставки — на свой риск. Ранний сезон / малая выборка = повышенная дисперсия. Проверять линии перед ставкой.

## Тон
- Спокойный, аналитический, без хайпа.
- Честный по поводу неопределённости.
- Фокус на «высокой вероятности» и «логической опоре», а не на «гарантированном проходе».

## Пример формулировки сильного аргумента
«Высокая статистическая опора (атака + дом + высота vs сильный, но не доминирующий соперник), коэффициент в целевом диапазоне, оценка вероятности выше implied».

## Запрещено
- Обещать «железные» результаты.
- Рекомендовать больше 2–3 событий без явной необходимости.
- Игнорировать актуальные травмы и движение линий.
